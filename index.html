I M ENTERPRISES - B2C Billing

📊 Excel Statement → Create B2C Bills

Upload your Current Account statement in Excel format.

The app reads the Transactions sheet and uses the Credit (₹) column as B2C sales.

Included: Normal credits + BULK POSTING credits
Excluded: Only credits below ₹10

Excel dates are read as calendar dates without timezone conversion, so a transaction dated 01/07/2026 remains 01/07/2026.
Select Txn Date Description Reference Credit GST Particulars Status

⚙️ Editable GST / Category Rules

These rules decide the GST rate and category from the transaction amount.

Default: ₹10 to ₹300 → Cleaning & Housekeeping Products → 18%
Above ₹300 → Baby Products → 5%

You can edit these ranges whenever required.

📑 Excel Report Contents

The downloaded workbook contains:

1. Sale Bills
Individual B2C bills and original transaction details.

2. GSTR-1 B2C
Consolidated B2C data grouped by Place of Supply and GST rate, with taxable value, CGST, SGST, IGST, GST and invoice value.

3. GSTR-1 Summary
5%, 18% and overall totals.

4. Documents Issued
Invoice count and invoice series information.

HSN
HSN is not automatically invented from bank transactions. Because one bank transaction can represent multiple products, the app does not create false product-level HSN information.
